# Evolve target:观点型 news-collector

Use this when evolving `news-collector` from a news summarizer into a research-editor style skill.

## Goal
Improve `news-collector` so the daily report is not a flat list of news items. It should produce structured judgment across three layers:

1. **模型层（基座层）**
   - New models, benchmarks, capability jumps, pricing/deployment implications
   - Compare against incumbent models when possible
   - Explain what actually improved: coding, tool use, reasoning, long context, multimodal, latency/cost

2. **Agent 层（应用能力层）**
   - Agent products, orchestration, tool use, computer use, async/multi-agent workflows
   - Judge whether the change is driven by real model progress or mostly product packaging
   - Explain downstream impact on automation reliability and practical usefulness

3. **工作流 / 编程范式层**
   - Changes in how people build, code, review, delegate, and coordinate work with AI
   - Highlight meaningful workflow shifts rather than feature noise
   - Emphasize what may change engineering practice over time

## Desired output behavior
For important items, prefer analysis over mere summary. The skill should answer:
- 它属于哪一层？
- 核心增量是什么？
- 与已有主流方案相比，强在哪 / 弱在哪？
- 影响路径是什么？会传导到哪些下游能力？
- 时间尺度是什么：短期显著、中期转折、还是长期基座变化？

## Editorial bar
- Quality over quantity
- Be willing to say an update is mostly packaging, not substantive progress
- Prioritize signal useful to AI engineers and workflow-oriented users
- Distinguish short-term hype from long-term capability shifts

## Anti-patterns
- Flat bullet lists with no ranking or analysis
- Repeating launch copy without comparison
- Treating every product update as equally important
- Overstating uncertain claims when evidence is thin
